# PRTS · 源石协议 (Originium Protocol)

DeepSeek Harness 专属战术工业风主题插件：**`dsh-theme-prts-originium`**（v1.4.1）。

```bash
# 在 DeepSeek Harness 中一键安装：
dsh plugin --profile desktop add github:Nefelibater/dsh-theme-prts-originium
```

## 界面

- 深色终端：冷墨蓝、灰白文字、少量琥珀金定位线。
- 浅色档案：冷灰青纸面、深墨文字、褐金色关键操作。
- 欢迎页：PV-4 启发的几何测绘场与可拖动旋转的 3D 源石晶簇。标本放大，名称与操作放在独立底栏，不与测绘文字交叠。
- 侧栏：档案导航、直线选中标记。点开角落的「P / 01」，才会显露普瑞赛斯的三张记忆影像；左右按钮或方向键切换，编号同步更新并记住选择。
- 对话：稳定的不透明阅读底板，独立的代码、表格与折叠过程层级。
- 输入：独立指令铭牌、刻度条、阅读面与工具栏分区；金色切角发送按钮、可见的键盘焦点。
- 弹层：不透明底色，不切掉菜单、焦点环或溢出内容。
- 左下角「专注阅读」收起装饰，保留全部功能与主题配色。此偏好仅保存在本插件的本地设置键中。

跟随 Harness 自己的浅色 / 深色 / 系统设置；不强制改外观。正文背景没有噪点、扫描线、磨砂或持续动画。

## 3D 源石

按用户提供的二维源石轮廓重建：224 块大小不同的晶体与碎片，主体 7,398 个三角面；加上细线菱形和柔和光晕，共 8,134 个三角面。背面和厚度是本次设计补全，并非官方模型的提取或精确复原。

1.3 增加参考图中的象牙白空心菱形、局部暗红辉光与周边切面的红色反照。菱形有薄边和实际空间位置，随源石旋转并接受遮挡。材质改为更深的黑色底、明亮的局部镜面反射与细微裂纹；光印内部保持暗色，不变成实心发光宝石。

- 在欢迎页直接拖动旋转；键盘方向键微调，`Home` 复位，`+` / `−` 缩放。滚轮仍用于页面滚动。
- 点击标本旁的 **⤢** 打开放大观察窗口，点击「关闭」或 `Esc` 返回。旁边的 **↺** 复位视角。
- 1.4.1 的菱形围绕自身中心缓慢放大、缩小（约原尺寸的 **88%–112%**），与 **6 秒**呼吸光效同步；变大时更亮，收缩时红光减弱。红色光晕也轻微扩张，晶体主体保持原尺寸。标本旁的 **Ⅱ / ▷** 可暂停或播放，首页与放大窗口共享暂停状态。
- 光效上限为每秒 20 帧。页面隐藏、标本离开可见区域、进入专注模式或被放大窗口覆盖时停止循环；系统开启「减少动态效果」时保持静态。暂停后仅在交互、尺寸或配色变化时重绘。
- 不支持 WebGL 时自动显示原有源石图片；窄窗口收起主视觉，优先保留输入和阅读空间。
- `model/originium-crystal.glb` 是可单独使用的标准 3D 模型；包含相同的晶体、空心菱形与光晕几何，并导出清漆材质和红色点光。主题内的程序化细纹与灯箱反射属于专用着色器；其他查看器采用标准材质近似，外观取决于灯光和扩展支持。

## PRTS 启动动画

打开客户端时播放约 **3.3 秒**：坐标定位 → 菱形晶体与轨道校准 → PRTS 字标显现 → 返回界面。深浅模式分别采用墨蓝和冷灰青底色，晶体内的金色线条呼应源石能量。

- 点击画面、点击「跳过动画」或按任意键立即结束，不会等待动画完成才能使用。
- 侧栏底部的 **↻** 可以重播；旁边的 **⋮** 可关闭「启动时播放」，偏好会保留。
- 系统开启「减少动态效果」或强制颜色时不播放；专注阅读模式也跳过自动开场。
- 同一客户端页面中只自动播放一次，不在切换会话时重播；刷新或重启会重新播放。
- 这是界面开场动画，不代表模型连接、后台任务或真实加载进度。没有声音、频闪和循环动画。

## 安装

1. 在 Harness 的插件管理中暂时停用原来的主题及其他正在启用的皮肤。原插件仍保留，可随时切回。
2. 选择「安装外部 bundle」，填写**这个文件所在的文件夹路径**。选择包含 `package.json` 和 `cordis.patch.yml` 的 `prts-originium-theme` 文件夹。
3. 启用「PRTS · 源石协议」。刷新界面；若客户端没有更新，再重启 Harness。
4. 在设置中分别切换浅色和深色；在左下角测试「专注阅读」。

当前目录可直接安装，无需构建、下载依赖或改 profile 配置。安装后请保持目录位置不变，因为本地安装可能使用链接。如果要搬到其他位置，先完整复制文件夹，再从新位置安装。

## 预览

打开 `preview.html` 可查看独立的交互预览：支持明暗切换、欢迎页 / 对话切换、折叠侧栏、专注模式、记忆档案、输入、附件菜单和设置弹层。点击顶部「启动动画」播放实时时序，「定格分镜」查看停留画面。预览中的会话和按钮为演示，不会向模型发送消息，也不会访问真实 Harness。

预览使用与插件相同的构建产物，但宿主界面是按本机源码钩子制作的模拟布局。因此它可以验证视觉与基本交互，不能代替安装后的真机检查。

## 验证与边界

运行 `node scripts/verify.mjs` 检查：包契约与清理、专注与启动偏好、三张图集循环和存储异常、模型几何与 GLB 导出、WebGL 失效回退，以及 56 组文字 / 表面的对比度（最低 **5.12:1**）。结果保存在 `verification.json`。

独立预览已检查深浅模式、启动分镜、动画跳过与开关持久化、角落档案展开、键盘专注切换、窄窗口、长代码 / 表格独立滚动与模拟发送。详见 `VISUAL-QA.md`；`preview-*.jpg` 是预览截图。

这次未连接真实 Harness 页面进行安装验证：该访问被浏览器权限检查拒绝。插件根据本机应用中提取的实际服务契约、属性钩子与 slot 定义开发。宿主升级后仍需检查样式类名片段的兼容性。

安装后建议核对一次：欢迎页、长回答、代码横向滚动、表格、折叠工具过程、模型菜单、附件菜单、设置弹层、右侧栏、窄窗口、专注模式，以及停用后的恢复。

## 修改和构建

- `src/theme.css`：UI、布局、装饰与明暗变量。
- `src/schematic.svg`：原创几何测绘场与源石晶体切面。
- `src/boot.css`：有限时长的开场时序、分镜与响应式规则。
- `src/palette.json`：65 个语义 token（含构建时加入的侧栏 token）。
- `src/client.template.js`：品牌、标本、记忆档案、专注 / 启动开关和完整生命周期。
- `src/originium-mesh.mjs`：可重复生成的原创晶簇几何。
- `src/originium-viewer.js`：本地 WebGL 材质、按需绘制、旋转与资源清理。
- `assets/`：本地素材；来源见 `SOURCES.md`。
- `scripts/build.mjs`：把样式、token 和资源内嵌到 `client.js`。
- `scripts/export-model.mjs`：导出与主题几何一致的 GLB 文件。
- `scripts/export-asset.mjs`：另存独立素材包，含自包含离线动态预览、GLB 和可复用源码。用预览的「导出透明 PNG」可保存当前视角。

修改源文件后运行 `npm run build` 和 `npm test`，然后刷新 Harness。无需安装依赖；不要直接编辑自动生成的 `client.js`。
